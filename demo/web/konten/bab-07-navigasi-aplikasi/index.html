Bab 7 — Navigasi Aplikasi

Rute dari struktur folder · Pertemuan 7 · Sub-CPMK 4.1. Bab 5 dan Bab 6 menghasilkan layar; bab ini menyambung layar-layar itu menjadi satu aplikasi yang bisa ditelusuri pengguna. Kamu akan mempelajari pola navigasi mobile (stack, tab, drawer), memasang Expo Router pada project template blank, mengirim parameter antar layar, menyusun nested navigation, memakai siklus hidup layar, dan melindungi layar yang hanya boleh dibuka setelah masuk.

Pertanyaan pembuka deck: “Siapa yang pernah menekan tombol kembali lalu mendarat di layar yang salah?”

Tampung jawabannya tanpa dikoreksi dulu — deck menyimpan pertanyaan ini sampai pembahasan layar terlindungi di bagian 3.

Tujuan Pembelajaran

Setelah bab ini, kamu bisa:

  • Menjelaskan konsep navigasi mobile serta pola stack, tab, dan drawer
  • Mengimplementasikan setup Expo Router pada project template blank
  • Membedakan navigasi deklaratif (<Link>) dan imperatif (router.push)
  • Menerapkan dynamic route dan pengiriman parameter antar layar
  • Merancang nested navigation, useFocusEffect, dan layar terlindungi

Peta halaman

  • Bagian 1 — Pola Navigasi Mobile (subbab 7.1–7.4): konsep navigasi dan riwayat, tiga pola stack/tab/drawer, tiga perbedaan stack dan tab, lalu latihan memilih pola.
  • Bagian 2 — Expo Router: Rute dari Folder (subbab 7.2, 7.6, 7.9): file-based routing, tiga penyesuaian setup pada project blank, grup rute bertanda kurung, dan peta enam file aplikasi praktikum.
  • Bagian 3 — Layar, Parameter & Perlindungan (subbab 7.5–7.8): stack di layout akar, Link vs router, parameter string, tab berisi stack, useFocusEffect, dan layar terlindungi.
  • Praktikum: aplikasi Aplikasi Manajemen Data Mahasiswa lengkap (Login → Beranda → Daftar → Detail → Form), troubleshooting, dan kuis kilat.

Yang perlu diketahui sebelum membaca

Bab ini mengandaikan project template blank dari Bab 2 (perintah npx create-expo-app dan Expo Go) dan component, state, serta useEffect dari Bab 4. Komponen React Native (View, Text, Pressable, FlatList) dipakai dari Bab 5 dan Bab 6 tanpa dijelaskan ulang. Peta rute aplikasi praktikum di bagian 2 adalah kontrak yang harus dipenuhi praktikum bab ini.

Setiap kode di halaman-halaman berikut disalin verbatim dari buku/bab-07-navigasi-aplikasi.md atau deck slides/bab-07-navigasi-aplikasi.md. Kode dalam panel sebelum/sesudah yang bertanda ilustrasi disusun untuk memperjelas konsep dan bukan salinan persis sumber; labelnya menyebut sumbernya dengan jujur.
