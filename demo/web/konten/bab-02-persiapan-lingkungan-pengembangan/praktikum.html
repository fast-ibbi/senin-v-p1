Praktikum Bab 2 — Proyek Expo Pertama

Satu pekerjaan besar hari ini: dari lingkungan kosong sampai teks “Halo, Dunia!” tampil di layar — lewat Expo Go di ponsel, emulator Android, atau perangkat fisik. Di tengahnya kamu sengaja merusak satu baris kode untuk melatih membaca pesan galat, lalu memperbaikinya.

Tujuan praktikum

Setelah menyelesaikan praktikum ini, kamu mampu:

  1. membuat proyek Expo pertama dengan templat blank (JavaScript polos);
  2. menjalankan npx expo start dan memahami antarmuka terminalnya;
  3. melihat aplikasi berjalan pada tiga jalur: Expo Go, emulator Android, dan perangkat fisik;
  4. mengubah kode “Hello World” dan membuktikan Fast Refresh bekerja;
  5. melatih diagnosis kendala lingkungan lewat daftar Troubleshooting.

Kebutuhan

  • Laptop atau komputer (Windows, macOS, atau Linux) dengan koneksi internet.
  • Node.js LTS terbaru (minimal 22) yang sudah terverifikasi lewat node --version.
  • Visual Studio Code (disarankan) beserta ekstensi ESLint dan Prettier.
  • Ponsel Android atau iOS dengan Expo Go terpasang, dan/atau Android Studio untuk emulator — setidaknya salah satu wajib tersedia agar hasil praktikum terlihat.

Persiapan

  1. Pastikan Node.js dan npm terverifikasi: jalankan node --version dan npm --version, lalu catat kedua nomor versi untuk laporanmu.
  2. Buat folder kerja khusus, misalnya proyek-kuliah, dan jadikan folder itu direktori aktif terminal.
  3. Jika memakai ponsel, pastikan Expo Go terpasang dan ponsel berada di Wi-Fi yang sama dengan laptop.
  4. Jika memakai emulator, nyalakan Android Studio, buat satu perangkat virtual lewat AVD Manager, lalu jalankan emulator sebelum langkah kerja dimulai.
  5. Kalau memakai komputer laboratorium kampus yang terkunci, koordinasikan dengan pengelola lab lebih dulu — Node.js LTS dan VS Code wajib tersedia di sana.

Langkah kerja

  1. Buka terminal (PowerShell atau Command Prompt di Windows; Terminal di macOS dan Linux), lalu arahkan ke folder kerja dengan cd proyek-kuliah.
  2. Buat proyek: jalankan npx create-expo-app aplikasi-pertama --template blank. Perhatikan prosesnya — npx mengunduh alat pembuat proyek, lalu npm memasang seluruh dependensi ke node_modules. Baca pesan sukses di akhir.
  3. Masuk ke folder proyek: cd aplikasi-pertama, lalu telusuri isinya dengan ls (macOS/Linux) atau dir (Windows), dan bandingkan dengan struktur folder di bagian 4.
  4. Buka di VS Code: code .. Di panel Explorer, buka App.js dan amati isinya.
  5. Nyalakan server: npx expo start. Tunggu sampai muncul kode QR dan alamat seperti exp://192.168.x.x:8081.
  6. Jalur Expo Go: buka Expo Go di ponsel lalu pindai kode QR — di iPhone lewat aplikasi Kamera, di Android lewat pemindai di dalam Expo Go. Percobaan pertama memerlukan beberapa detik untuk bundling.
  7. Jalur emulator: bila emulator sudah menyala, tekan a di terminal Expo.
  8. Jalur perangkat fisik (opsional): sambungkan ponsel Android dengan kabel USB (Developer options dan USB debugging aktif), verifikasi dengan adb devices, lalu tekan a.
  9. Ubah dan rusak sengaja: ganti isi Text menjadi namamu, simpan, dan amati Fast Refresh. Setelah itu hapus satu tanda kutip, simpan, dan baca layar kesalahan merah beserta pesannya — lalu kembalikan kode yang benar.
  10. Hentikan server dengan Ctrl+C setelah selesai, dan simpan folder proyek karena ia dipakai lagi di beberapa bab berikutnya.

Kode: App.js

Penjelasan kode

Berkas ini adalah komponen App — fungsi JavaScript yang mengembalikan deskripsi antarmuka. Dua baris import di awal meminjam alat dari pustaka: StatusBar dari paket expo-status-bar (pengatur bilah status atas layar), serta StyleSheet, Text, dan View dari react-native. View adalah kotak penampung antarmuka (seperti div di web), Text adalah teks yang tampil, dan StyleSheet.create adalah cara React Native menulis gaya. Ketiganya baru dikupas mendalam di Bab 5, jadi di sini cukup tiru polanya.

Fungsi App mengembalikan struktur: satu View berisi dua Text dan satu StatusBar. Gaya ditulis sebagai objek dengan nama deskriptif — kontainer, judul, keterangan. flex: 1 membuat kotak memenuhi layar, alignItems dan justifyContent memusatkan isi, sedangkan fontSize, fontWeight, dan color mengatur tampilan huruf.

Pola ini mengikuti template resmi SDK 57. Kamu dapat mengetik ulang, mengganti teksnya, lalu mengamati perubahannya — dan itulah bentuk pekerjaan sehari-hari seorang pengembang antarmuka: mengubah satu nilai, menyimpan, melihat hasilnya.

Hasil yang diharapkan

  1. Dua nomor versi muncul saat node --version dan npm --version dijalankan.
  2. Folder aplikasi-pertama terbentuk, dan npx create-expo-app aplikasi-pertama --template blank selesai tanpa galat.
  3. Terminal Expo menampilkan kode QR dan alamat exp://...:8081.
  4. Aplikasi tampil di Expo Go dan/atau emulator Android dengan teks “Halo, Dunia!” di tengah layar.
  5. Fast Refresh bekerja: setelah App.js diubah dan disimpan, tampilan berubah sendiri dalam 1–2 detik; layar kesalahan merah muncul ketika kode sengaja dirusak, lalu hilang setelah dikembalikan.
  6. adb devices menampilkan entri emulator-5554 atau nama perangkat fisikmu saat terhubung.

Troubleshooting

GejalaPenyebabSolusi
node: command not found / 'node' is not recognized Node.js belum terpasang, atau pemasangannya tidak tercatat di PATH Pasang Node.js LTS dari nodejs.org (Windows: centang “Add to PATH”), lalu buka terminal baru dan ulangi node --version
Peringatan bahwa port 8081 sedang dipakai Ada program lain yang menduduki port default Metro Tutup program itu, atau jalankan npx expo start --port 8082; di Windows netstat -ano | findstr 8081 lalu taskkill /PID <angka-pid> /F
Layar merah saat menyimpan, atau “Unable to resolve module …” Galat bundling Metro: kesalahan sintaksis, atau modul yang tidak ditemukan Baca baris pertama pesan galat (berkas dan barisnya disebut), perbaiki, simpan; bila tetap, jalankan npx expo start -c
Menekan a tidak membuka apa pun Emulator belum dinyalakan, atau AVD belum pernah dibuat Buka Android Studio > Device Manager, buat perangkat virtual bila belum ada, jalankan sampai selesai booting, lalu tekan a lagi
adb devices kosong atau berstatus unauthorized USB debugging belum aktif, kabel hanya untuk mengisi daya, atau ponsel belum menyetujui autentikasi Aktifkan USB debugging, ganti kabel data, setujui dialog “Izinkan debugging USB?”, cabut dan pasang ulang kabel
Kode QR tidak bisa tersambung (“could not connect”) Ponsel dan komputer berada di jaringan berbeda, atau jaringan memblokir komunikasi antarperangkat Hentikan server, lalu jalankan npx expo start --tunnel dan pindai ulang kode QR

Salah paham

Kegagalan lingkungan bukan kegagalan logika. Dua jam pertama praktikum sering habis untuk masalah PATH, bukan untuk materi. Ajarkan urutannya: baca pesan galat, kenali lapisan mana yang gagal (Node, npm, Metro, jaringan, atau perangkat), baru bertindak. Jangan memasang ulang seluruh proyek sebelum membaca pesan galatnya — itu menghapus petunjuk paling berharga yang kamu punya.

Yang harus teramati

  • Dua nomor versi — node --version dan npm --version menjawab dengan nomor, bukan pesan galat.
  • Folder proyek terbuat tanpa galat — aplikasi-pertama ada, dan isinya cocok dengan struktur di bagian 4.
  • Kode QR dan alamat LAN — npx expo start menampilkan exp://...:8081, bukti Metro bekerja.
  • Teks “Halo, Dunia!” tampil di Expo Go atau emulator Android.
  • Perubahan mengubah layar dalam 1–2 detik — Fast Refresh bekerja, dan layar merah muncul saat kode sengaja dirusak.
Laporan yang baik menyertakan tangkapan layar dan nomor versi, bukan hanya tulisan “berhasil”.

Kuis kilat

  1. Alat apa yang wajib terpasang sebelum menjalankan npx create-expo-app?
  2. Apa beda npm install <paket> dengan npx <perintah>?
  3. Kenapa buku ini memilih --template blank?
  4. Apa peran Metro Bundler saat npx expo start dijalankan?
  5. Port bawaan apa yang dipakai Metro Bundler?
Kunci kuis kilat
  1. Node.js — wajib ada sebelum alat Expo bisa dijalankan.
  2. npm install memasang paket ke proyek; npx menjalankannya tanpa pemasangan permanen.
  3. blank menghasilkan JavaScript biasa, sedangkan templat bawaan memakai TypeScript dan menyertakan Expo Router.
  4. Ia membundel modul JavaScript lalu mengirimkannya ke perangkat.
  5. Port bawaan Metro Bundler adalah 8081.

Ringkasan bab

  1. Node.js adalah runtime JavaScript di luar browser — prasyarat Expo CLI dan Metro Bundler.
  2. npm mengelola dependency dan mencatatnya di package.json; npx menjalankan perintah tanpa memasang permanen.
  3. Pilih satu pengelola paket dan konsisten; mencampurnya menghasilkan lockfile berbeda antaranggota tim.
  4. VS Code dengan ESLint dan Prettier adalah meja kerjanya; hindari ekstensi yang sudah diarsipkan pembuatnya.
  5. Expo Go menguji tanpa build dengan harga keterbatasan fitur native; emulator untuk uji lintas versi, perangkat fisik untuk sensor dan pengalaman nyata.
  6. iOS Simulator hanya tersedia di macOS; pengguna Windows menguji iOS lewat iPhone fisik ber-Expo Go atau build awan (Bab 15).
  7. --template blank berarti JavaScript polos, dan npx expo start menjalankan Metro di port 8081; --tunnel mengatasi jaringan yang memblokir komunikasi antarperangkat.
