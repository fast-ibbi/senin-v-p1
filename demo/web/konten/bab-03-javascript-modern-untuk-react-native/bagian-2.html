Array dan Object adalah Tipe Rujukan

Array menyimpan sekumpulan nilai berurutan, sedangkan object menyimpan pasangan nama–nilai yang disebut properti. Keduanya adalah tipe rujukan: variabel menyimpan alamat data, bukan salinan nilainya. Konsekuensi yang sering menjerat pemula: const a = [1, 2]; const b = a; b.push(3); mengubah a juga, karena keduanya menunjuk array yang sama.

Analoginya: menyalin rujukan seperti memberi nama panggilan kedua pada orang yang sama — mengubah nama panggilan tidak memunculkan orang kedua. Pola inilah yang wajib dipahami karena React menekankan pembaruan data secara immutable: data lama tidak diubah, melainkan diganti dengan data baru.

Bagian array memperlihatkan tiga operasi dasar: menambah elemen di belakang dengan push, memeriksa keberadaan dengan includes, dan memotong salinan dengan slice — slice(1, 3) mengambil indeks 1 sampai sebelum 3, sehingga hasilnya dua elemen. Tiga baris terakhir adalah peringatan terpenting subbab ini: menyalin objek dengan tanda sama dengan hanya menyalin rujukannya.

Salah paham

Aliasing jarang muncul di latihan kecil, tetapi sangat sering terjadi saat mengubah state React. Kebiasaan baiknya: perlakukan data sebagai sesuatu yang “dipinjam”, dan ketika perlu versi baru, salin dulu dengan spread seperti pada subbab 2.2.

Destructuring dan Spread Operator

Destructuring adalah cara mengambil nilai dari objek atau array langsung ke dalam variabel, dalam satu baris. Sebelum ES6, cara lama menulis satu baris per properti — banyak baris, banyak pengulangan, banyak tempat untuk salah ketik. Destructuring array juga menjadi dasar pemakaian hook useState di React: fungsi itu mengembalikan array dua elemen [nilai, fungsiPengubah] yang langsung diberi nama dalam satu baris.

Spread operator ditulis dengan tiga titik ... dan menyebarkan isi array atau properti objek ke tempat tujuan. Ia dipakai untuk menyalin, menggabungkan, dan membuat objek baru dari objek lama dengan beberapa properti diperbarui. Perhatikan kemiripan penulisannya dengan rest parameter di subbab 1.6: keduanya memakai ..., tetapi rest mengumpulkan sisa nilai, sedangkan spread menyebarkan isi wadah.

Sintaks nim: nomorInduk memberi nama variabel baru, dan prodi = 'Belum diketahui' menyediakan nilai bawaan karena properti itu tidak ada di objek. Destructuring array bekerja berdasarkan urutan: pertama dan kedua mengambil indeks 0 dan 1, sedangkan ...sisaNilai mengumpulkan sisanya menjadi array [75, 88] — pola yang identik dengan cara kerja useState di Bab 4.

map, filter, reduce, dan find

Ketiga metode ini adalah jalan utama pengolahan data di JavaScript modern: alih-alih menulis perulangan manual yang memberitahu komputer bagaimana memproses, kita menyatakan apa yang diinginkan. map mengubah setiap elemen dan mengembalikan array baru berukuran sama; filter memilih elemen yang memenuhi kondisi dan mengembalikan array baru yang sama panjang atau lebih pendek; reduce menggabungkan seluruh elemen menjadi satu nilai.

Selain ketiganya, kenali find yang mengembalikan elemen pertama yang cocok, some yang menguji minimal satu elemen, dan every yang menguji semua elemen. find untuk pencarian satu data, some untuk pemeriksaan cepat, dan every untuk penjaminan.

Argumen tiap metode adalah sebuah callback yang menerima elemen array sebagai parameter pertama — di sini dinamai m, singkatan dari mahasiswa. reduce menerima akumulator total dan elemen m dengan nilai awal 0; tanpa nilai awal, reduce menjadikan elemen pertama sebagai akumulator dan gagal pada array kosong. Perhatikan pula bahwa find mengembalikan objek, bukan array, sehingga budi?.nama dari subbab 1.3 dipakai agar aman bila NIM tidak ditemukan.

Salah paham

Pemula sering memakai filter untuk pekerjaan yang sebenarnya mencari satu data. filter mengembalikan array, find mengembalikan satu elemen. Salah pilih alat di sini berarti kode pemanggil harus menulis [0] dan menangani array kosong yang tidak pernah dibutuhkan.

Rantai filter lalu map: Laporan yang Dulu Manual

Rantai filter(...).map(...) terbaca wajar dari kiri ke kanan: saring dulu, ubah sesudahnya. Perulangan manual memberi tahu komputer bagaimana, sedangkan rantai ini menyatakan apa yang diinginkan; hasilnya tidak mungkin salah indeks. Contoh berikut merangkai ketiga metode pada satu array.

filter menyisakan dua nilai di atas ambang, map mengubahnya menjadi teks yang siap ditampilkan, dan reduce menjumlahkan keduanya sebelum dibagi banyaknya data. Perhatikan bahwa berprestasi dipakai ulang untuk dua keperluan berbeda — inilah keuntungan memisahkan setiap langkah ke variabel: mudah dibaca dan mudah diuji.
