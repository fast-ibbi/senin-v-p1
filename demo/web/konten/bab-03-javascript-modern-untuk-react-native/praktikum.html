Praktikum Bab 3 — Pengolah Nilai Mahasiswa

Dua berkas JavaScript, satu perintah terminal, dan satu berkas JSON sebagai bukti. Praktikum ini adalah versi kecil dari otomatisasi laporan akademik: satu script yang dapat dijalankan ulang dengan hasil yang konsisten.

Tujuan praktikum

Setelah menyelesaikan praktikum ini, kamu mampu:

  1. mengimplementasikan deklarasi variabel const/let dan tipe data pada data nyata;
  2. membuat modul data lima mahasiswa baku dengan export;
  3. mengolah array dengan map, filter, reduce, dan find — daftar ringkas, mahasiswa berprestasi, serta rata-rata IPK per prodi;
  4. menyusun program asinkron dengan async/await dan try/catch untuk menyimpan rekap hasil ke berkas JSON;
  5. memverifikasi sintaks dengan node --check dan menjalankan program dengan node <berkas>.

Kebutuhan

  • Node.js LTS versi 22 atau lebih baru (cara memasangnya ada di Bab 2).
  • Terminal: Command Prompt atau PowerShell di Windows, Terminal di macOS dan Linux.
  • Editor teks apa pun; Visual Studio Code disarankan.
  • Tidak ada dependency yang perlu dipasang — praktikum ini murni JavaScript bawaan Node.js.

Persiapan

  1. Buka terminal, lalu pastikan Node.js terpasang dengan node --version. Versi yang tampil harus 22 atau lebih tinggi.
  2. Buat folder kerja baru bernama praktik-js dan jadikan folder itu direktori aktif.
  3. Buka folder tersebut di Visual Studio Code melalui menu File → Open Folder agar penulisan kode lebih nyaman.

Langkah kerja

  1. Buat berkas data-mahasiswa.mjs berisi lima data mahasiswa baku — berkas ini menjadi modul data yang diekspor.
  2. Buat berkas pengolah-nilai.mjs berisi program utama: ringkasan dengan map, daftar berprestasi dengan filter, rata-rata per prodi dengan filter lalu reduce, pencarian dengan find, dan penyimpanan hasil dengan async/await.
  3. Periksa sintaks kedua berkas dengan node --check data-mahasiswa.mjs dan node --check pengolah-nilai.mjs. Bila tidak ada keluaran apa pun, sintaks dinyatakan benar.
  4. Jalankan program dengan node pengolah-nilai.mjs dari dalam folder praktik-js.
  5. Buka berkas hasil-rekap.json yang terbentuk di folder yang sama, lalu bandingkan isinya dengan penjelasan di bagian hasil yang diharapkan.
  6. Opsional: ketik berkas package.json berisi "type": "module", ganti ekstensi kedua berkas dari .mjs menjadi .js, lalu jalankan kembali — hasilnya harus sama.

Penjelasan kode

Berkas data-mahasiswa.mjs adalah modul murni: ia hanya mendeklarasikan dan mengekspor satu nilai bernama daftarMahasiswa — array lima objek mengikuti struktur { id, nim, nama, prodi, angkatan, ipk, email, telepon } yang sama dengan data baku buku ini. Berkas ini tidak mencetak apa pun; tugasnya hanya menyediakan data. Inilah pembagian kerja sistem modul pada subbab 3.8: berkas data terpisah dari berkas logika, dan keduanya dapat diuji serta diubah secara mandiri.

Program utama dibuka dengan dua baris import: baris pertama mengambil data dari modul tetangga, baris kedua mengambil writeFile — fungsi bawaan Node.js untuk menulis berkas secara asinkron — dari namespace node:fs/promises. Enam fungsi berikutnya mewakili satu teknik per fungsi. buatDaftarRingkas memakai map untuk memproyeksikan empat kolom penting; cariBerprestasi memakai filter dengan ambang IPK; hitungRataRata menggabungkan filter dan reduce lalu membaginya dengan banyaknya data — perhatikan penjagaan dataProdi.length === 0 agar tidak membagi dengan nol; cariMahasiswa memakai find; dan daftarProdiUnik memanfaatkan Set yang menolak duplikat, lalu disebar kembali menjadi array dengan spread.

Fungsi simpanHasil menunjukkan pola asinkron baku: bertanda async, memakai await writeFile(...), dan membungkus seluruh operasi dalam try/catch. Bila folder tujuan tidak ada atau hak akses ditolak, writeFile melempar error dan catch mencetak error.message tanpa menghentikan program. Fungsi main merangkai semuanya secara berurutan dan, pada bagian akhir, membangun objek rekap; setiap prodi dipetakan menjadi { prodi, rataRata } lalu disimpan dengan JSON.stringify(data, null, 2) — argumen null, 2 membuat JSON ditulis dengan indentasi dua spasi agar mudah dibaca manusia.

Hasil yang diharapkan

  1. Tidak ada error di terminal setelah node pengolah-nilai.mjs dijalankan.
  2. Urutan dan angka keluaran sesuai contoh di bawah — lima baris data, dua mahasiswa berprestasi, empat rata-rata prodi, dan dua baris pencarian NIM.
  3. Berkas hasil-rekap.json terbentuk di folder yang sama dengan berkas program.
  4. Isi berkas itu memuat jumlahMahasiswa bernilai 5, array daftarRingkas lima baris, berprestasi berisi dua nama, dan rataRataIpkPerProdi berisi empat objek.

Angka di atas berasal dari eksekusi nyata penulis buku, sehingga satu-satunya nilai yang boleh berbeda di komputer kamu adalah disimpanPada, yaitu waktu penyimpanan.

Salah paham

Praktikum ini tanpa dependency, jadi kegagalan hampir selalu berasal dari ekstensi berkas atau folder kerja yang salah, bukan dari paket yang belum dipasang. Jangan menjalankan npm install untuk mencari jalan keluar: tidak ada yang perlu dipasang, dan menambah paket hanya menambah hal yang bisa salah.

Yang harus teramati

  • Rata-rata per prodi — Sistem Informasi 3.20, Teknik Informatika 3.82, Informatika 3.20, Rekayasa Perangkat Lunak 3.61.
  • Mahasiswa berprestasi dengan IPK minimal 3.5 — Siti Aminah 3.82 dan Dewi Lestari 3.61.
  • Berkas keluaran — hasil-rekap.json terbentuk dan memuat jumlahMahasiswa bernilai 5.
  • Bukti, bukan kesan — sertakan tangkapan layar keluaran terminal dan isi berkas JSON, bukan hanya kalimat “sudah berhasil”.
Keberhasilan diukur dari tiga penanda: keluarannya cocok, berkasnya terbentuk, dan isi berkasnya benar — bukan hanya dari tidak adanya pesan error.

Kuis kilat

  1. Hasil [5, 8, 3, 9].filter((x) => x > 4) adalah…
  2. Hasil [1, 2, 3, 4].reduce((total, x) => total + x, 0) adalah…
  3. Agar import berjalan di Node.js tanpa konfigurasi tambahan, ekstensi berkasnya…
  4. Pernyataan yang benar tentang arrow function adalah…
Kunci kuis kilat
  1. [5, 8, 9] — filter menyimpan elemen yang memenuhi syarat, dan angka 3 gugur.
  2. 10 — reduce menjumlahkan semua elemen dengan nilai awal 0.
  3. .mjs — alternatifnya "type": "module" di package.json.
  4. Arrow function tidak punya this sendiri — sebabnya ia mendominasi kode React.

Ringkasan bab

  1. const untuk nilai tetap dan let untuk nilai yang berubah; keduanya block scoped, dan const tidak membekukan isi objek.
  2. Pakai ===, tambah ?. dan ??; ingat enam nilai falsy saat menulis syarat.
  3. Arrow function lebih ringkas dan tanpa this sendiri — dasar kode React.
  4. map, filter, reduce, destructuring, dan spread mengolah data tanpa mengubah aslinya.
  5. Modul memecah kode; async/await dengan try/catch adalah pola baku memanggil data.
