Bab 9 — State Management

State lokal dan global, Context API, custom hook · Pertemuan 9 · Sub-CPMK 4.2. Bab ini menjawab satu pertanyaan lanjutan dari Bab 4: kalau data harus dipakai bersama oleh banyak layar, di mana ia disimpan supaya semua pembacanya melihat nilai yang sama?

Pembuka deck: “Bab 4 mengajari satu komponen mengingat datanya sendiri; hari ini data itu harus dipakai bersama oleh banyak layar.”

Pertanyaan pemicunya: “Kalau dua layar masing-masing menyimpan salinan keranjang, layar mana yang benar?” Tampung jawaban tanpa dikoreksi dulu — halaman bagian 1 yang menjawabnya.

Tujuan pembelajaran

  • Menjelaskan perbedaan state lokal dan state global beserta trade-off-nya
  • Mengidentifikasi kondisi yang membutuhkan lifting state up atau Context API
  • Mengevaluasi kapan data tetap lokal dan kapan layak menjadi global
  • Mengimplementasikan Context API dengan JavaScript polos
  • Merancang custom hook useCart serta mengevaluasi Zustand dan Redux Toolkit

Peta halaman

  • Bagian 1 — Dari State Lokal ke State Global (subbab 9.1–9.2): cakupan state, latihan lokal-atau-global, lifting state up, prop drilling, Contoh 1 pemesanan minuman, dan studi kasus keranjang KRS.
  • Bagian 2 — Context API & Custom Hook (subbab 9.3–9.6): tiga bagian Context API, pola wadah-provider, kapan context dipakai dan dihindari, custom hook, useCart, tiga pertanyaan penyaring data global, tangga keputusan, serta pengantar Zustand dan Redux Toolkit.
  • Bagian 3 — Merancang State dan Membangun Keranjang (subbab 9.7): lima pertanyaan perancangan state, sumber kebenaran tunggal CartContext, provider di layout akar, dua layar satu sumber data, rantai ketukan “Tambah”, dan studi kasus Primadona.
  • Praktikum: aplikasi TokoKu lengkap (badge keranjang, kendali qty, total harga turunan), troubleshooting, dan kuis kilat.

Yang perlu diketahui sebelum membaca

Bab ini bertumpu pada dua bab sebelumnya: useState dan props dari Bab 4, serta struktur rute Expo Router dari Bab 7. Kode contoh memakai komponen React Native (View, Text, Pressable) karena project kuliah berjalan di Expo; konsepnya sama persis di web.

Pada project mata kuliah ini keranjang belanja adalah pilihan KRS, sehingga deck menyebut context-nya KrsContext dan hook-nya useKrs; pola dan kodenya sama persis dengan CartContext dan useCart di praktikum TokoKu, hanya nama domainnya yang berbeda.

Setiap kode di halaman-halaman berikut disalin verbatim dari buku/bab-09-state-management.md atau deck slides/bab-09-state-management.md, dengan label sumbernya di kepala blok kode. Perbandingan sebelum/sesudah menampilkan cara lama yang salah atau naif di samping cara yang benar; kode ilustrasi diberi label ilustrasi pada sumbernya.

Pertanyaan penuntun

Konsep mana di bab ini yang paling sering diuji? Hampir semua soal menuntut kamu memilih tingkat state yang tepat (lokal, diangkat, atau global) — perhatikan latihan A–D di bagian 1 dan tiga pertanyaan penyaring di bagian 2.
