Bab 4 — Dasar-Dasar React

Component, JSX, props, state, dan hook · Pertemuan 4–5. Bab ini menjawab satu pertanyaan: kalau data berubah, siapa yang memperbarui layar — kode kita, atau alatnya? Jawabannya UI = f(state): tampilan adalah fungsi dari state.

Pertanyaan pembuka deck: “Kalau data mahasiswa berubah, siapa yang seharusnya memperbarui layar? Kode kita atau alatnya?”

Tampung jawaban tanpa dikoreksi dulu — halaman bagian 1 yang menjawabnya.

Tujuan pembelajaran

  • Menjelaskan konsep UI deklaratif dan UI = f(state)
  • Menulis JSX yang benar dan membedakan component dari elemen
  • Menerapkan component yang dipakai ulang lewat props dan nilai default
  • Membedakan props dari state dan memperbarui state tanpa mengubahnya langsung
  • Menerapkan event, render kondisional, dan render daftar dengan key yang benar
  • Menerapkan siklus hidup sederhana dengan useEffect, termasuk cleanup
  • Mengevaluasi kapan useMemo dan useCallback benar-benar perlu

Peta halaman

  • Bagian 1 — Pola Pikir, Component & Props (subbab 4.1–4.4): kenapa React perlu ada, UI = f(state), component dan enam aturan JSX, props, lalu state dan useState.
  • Bagian 2 — Interaksi, Render & Komposisi (subbab 4.5–4.7): event handling, render kondisional tiga pola, render daftar dengan map dan key, serta komposisi component.
  • Bagian 3 — Hook: useEffect, useMemo, useCallback (subbab 4.8–4.9): efek samping dan cleanup, siklus hidup mount/update/unmount, dan kapan optimasi benar-benar perlu.
  • Praktikum: aplikasi Data Mahasiswa lengkap (filter program studi, detail per kartu, rata-rata IPK), troubleshooting, dan kuis kilat.

Yang perlu diketahui sebelum membaca

Bab 3 sudah menyediakan alat bahasanya (variabel, fungsi, array, objek, spread, map). Di bab ini alat itu dipakai untuk membangun antarmuka. Kode contoh memakai komponen React Native (View, Text, Pressable) karena project kuliah berjalan di Expo; di web, padanannya adalah elemen HTML biasa — konsepnya sama persis, dan padanan ini dibahas tuntas di Bab 5.

Setiap kode di halaman-halaman berikut disalin verbatim dari buku/bab-04-dasar-react.md atau deck slides/bab-04-dasar-react.md. Perbandingan sebelum/sesudah menampilkan cara lama yang salah atau naif di samping cara yang benar; tombol di kepala panel untuk berpindah.
