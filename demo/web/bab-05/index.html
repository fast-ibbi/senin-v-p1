Bab 5 — Dasar React Native

Halaman demo web untuk pertemuan 6, mata kuliah Pemrograman Mobile. Isinya enam halaman: lima halaman bagian dan satu halaman praktikum. Tiap bagian berisi penjelasan yang memperdalam poin-poin deck dengan isi buku, kode yang disalin verbatim dari slides/bab-05-dasar-react-native.md, buku/bab-05-dasar-react-native.md, atau praktikum/bab-05-*.md, lalu hasil yang diharapkan beserta alasannya. Halaman ini adalah petanya, bukan materinya.

Pertanyaan pembuka deck: “Kalau cara berpikirnya sama dengan React, kenapa kodenya harus berbeda?”

Tampung dua sampai tiga jawaban sebelum membuka halaman bagian mana pun. Jawaban lengkapnya baru muncul di Bagian 1, lalu dipakai ulang di empat bagian berikutnya.

Cara membaca halaman ini

Keluaran React Native di halaman bagian adalah tiruan HTML/CSS, bukan React Native sungguhan: tidak ada kode React Native yang dijalankan di peramban. Tiruan itu meniru lima aturan yang paling mudah dibuktikan — flexDirection bawaan column (CSS: row), alignItems bawaan stretch, flexShrink bawaan 0 (CSS: 1), box-sizing: border-box di semua komponen, dan tidak ada margin collapse. Di perangkat asli hasilnya bisa sedikit berbeda karena font perangkat dan pembulatan piksel.

Keluaran React Web bukan tiruan: peramban benar-benar merender HTML dengan aturan CSS yang ditampilkan, sehingga kolom itu bisa dipakai sebagai pembanding yang jujur — termasuk ketika hasilnya tidak seperti yang diharapkan.

Semua contoh statis. Tidak ada tombol, tab, atau isian yang bisa ditekan; keadaan lain ditampilkan sebagai bingkai terpisah supaya bisa dibandingkan tanpa mengklik. Satu-satunya yang hidup di halaman bagian adalah penggeser lebar, yang mengubah lebar semua bingkai sekaligus. Halaman peta ini tidak memuat bingkai, jadi tidak memuat penggeser itu.

Angka gaya — warna, jarak, radius, ukuran — ditulis inline pada markup tiruan dan diambil dari objek StyleSheet pada kode yang ditampilkan di subbab yang sama. Tidak ada angka yang dikarang: mengubah satu angka di kode berarti mengubah satu angka di tiruan.
